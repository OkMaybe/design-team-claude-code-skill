# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in this skill, please report it responsibly by opening a private issue or contacting the maintainer directly.

## Security Measures

This repository contains NO:
- API keys, tokens, or secrets
- Personal identifiable information (PII)
- Credentials or authentication data
- Copyrighted material (PDFs, ebooks)

All content is original design intelligence knowledge compiled into reference files.

## For Users

- Never commit .env files or API keys to this repository
- The .gitignore is configured to block common sensitive file patterns
- Review any changes before pushing to ensure no secrets are included
